Program ini digunakan untuk menghitung volume tabung dengan menggunakan fungsi (method).
Cara kerjanya:
Program meminta pengguna memasukkan jari-jari dan tinggi tabung.
Nilai tersebut dikirim ke fungsi hitungVolume(), yang menghitung volume dengan rumus
volume = π × r² × t.
Hasil perhitungan dari fungsi dikembalikan dan ditampilkan ke layar.
